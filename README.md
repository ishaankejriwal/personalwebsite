# ishaankejriwal.com

Four things I built, turned into toys. Next.js, Tailwind v4, three vanilla canvas games, no other dependencies.

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

Cabinet order and copy are in `src/app/page.tsx` and `src/components/stories.tsx`. Games live in `src/components/games`. Design notes in `DESIGN.md`, working rules in `AGENTS.md`, current state and open questions in `context.md`.
